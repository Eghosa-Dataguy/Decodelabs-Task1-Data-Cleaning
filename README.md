# Task 1: Data Cleaning and Preparation

## Project Overview

This task focused on preparing a raw dataset for analysis by performing essential data cleaning operations. The objective was to improve data quality, ensure consistency, and create a reliable dataset for future analysis and reporting.
## Dataset Cleaning Process

### 1. Duplicate Removal

* Identified and removed duplicate records from the dataset,where ***1,047,374*** duplicate values was found and removed
* Ensured that each record was unique  ***1,200 Unique values*** to prevent inaccurate analysis and reporting.

### 2. Handling Missing Values

* Examined the dataset for blank rows and empty cells.
* Replaced blank/missing values ***using Ctrl+A "To select the entire table", Ctrl+G "To highlight missing/blank values or cells" and replacing it with N/A (Not Available) using Ctrl+Enter key*** where appropriate to maintain data completeness and consistency.

### 3. Data Type Formatting

* Reviewed all columns and converted them into their appropriate data types.
* Ensured dates were stored in date format.
* Verified that numerical fields were stored as numbers.
* Confirmed that text fields were correctly formatted as text.

### 4. Text Standardization

* Corrected inconsistencies in text entries.
* Applied proper case formatting to improve readability and maintain uniformity.
* Converted text values to a consistent format where necessary.

### 5. Data Validation

* Checked for inconsistencies and irregularities after cleaning.
* Verified that all transformations were successfully applied.
* Ensured the dataset was accurate, complete, and ready for analysis.

## Tools Used

* Microsoft Excel / Power Query 
* Data Cleaning Techniques
* Data Preparation
* Data Validation Methods

## Key Outcomes

* Improved data accuracy and consistency.
* Eliminated duplicate records.
* Handled missing values effectively.
* Standardized text formatting and data types.
* Produced a clean and analysis-ready dataset.

## Conclusion

The data cleaning process transformed the raw dataset into a structured and reliable dataset suitable for analysis, visualization, and decision-making. Proper cleaning ensures that subsequent analytical tasks are based on accurate and high-quality data.
